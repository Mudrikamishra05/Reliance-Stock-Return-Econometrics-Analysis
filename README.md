Econometrics for Financial Decision Making
Multiple Regression and Volatility Analysis of Reliance Industries Stock Returns Using R
About the Project
This project analyzes Reliance Industries stock returns using econometric techniques in R Studio.

The study includes:

Multiple Regression Analysis
Multicollinearity Testing (VIF)
Breusch-Pagan Test
Durbin-Watson Test
Jarque-Bera Test
Robust Standard Errors
GARCH (1,1) Volatility Modelling
Structural Break Analysis
